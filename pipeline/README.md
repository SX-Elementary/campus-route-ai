# 中国人民公安大学 团河校区 · 地图与路网数据包

> 用途：给你那个「日程 + 路径规划」平台做底图和数据底座。
> 坐标系统一为 **GCJ-02（高德火星坐标）**，底图 z17 拼接，**1 像素 ≈ 0.92 米**。

## 零、交互平台（先看这个）

**双击 `web/index.html` 就能用**（Edge / Chrome，无需服务器、无需联网、无第三方库）。

![平台预览](web/preview.png)

| 能做什么 | 怎么操作 |
|---|---|
| 缩小 / 放大 / 平移 | 滚轮 / 双指缩放；按住拖动平移；`0` 适配视图 |
| **新增地标**（食堂、超市、澡堂、医务室、快递柜、校门…） | 双击地图空白处；或点「＋新增地标」后单击地图 |
| 填名称、选类别 | 弹窗里输入，12 个类别可选（食堂/超市/澡堂/医务室/快递/校门/楼门…） |
| 改位置 | 直接拖动标记；改完自动重新接入路网 |
| 改名 / 改类别 / 删除 | 双击标记，或右侧"选中项"面板；`Del` 键删除 |
| 看真实楼栋 | 顶部「卫星」切换到卫星底图（已做地理配准，和标注点严丝合缝） |
| 算步行路线 | 右侧选起点终点 → 计算路线；显示距离、耗时和沿路折线 |
| 保存 | 自动存浏览器本地（localStorage），刷新不丢 |
| 备份 / 迁移 / 交给我继续做 | 「导出」下载 JSON；「导入」恢复；「恢复初始」回到 19 个基础点 |

**关键设计**：新加的点会**自动垂足投影到最近的道路**并接入路网图 —— 所以你在食堂位置点一下，它立刻就能参与路径计算，不需要你画路。
浏览器控制台还有 `window.__campus` 钩子（`add / route / select / pois / graph / fit / zoom`），方便你后面接算法或做自动化。

## 三、坐标系与精度

- 底图：高德瓦片 `webrd0{1-4}`（含中文注记），z17；卫星：`webst0{1-4}` style=6，z18。
- 拼接脚本会打印图幅四角经纬度，`campus_data.json` 的 `geo_ref` 里也存了一份，
  像素 ↔ 经纬度换算：`lon = 116.353455 + px * 1.07289e-5`，`lat = 39.770548 - py * 8.24740e-6`。
- 校验方法：400 m 田径场在图上的长轴约 470 px ≈ 432 m，误差 < 8%，说明比例可靠。
- **点位误差约 ±30 m**（人工在高德注记上读点）。要更准就用 `campus_graph.json` 校正像素坐标。

## 五、数据结构（直接喂算法）

`campus_graph.json`（125 节点 / 129 边 / 54 个 POI 接入点）：
```json
{
  "nodes": [{"id": "N0", "px": [x, y], "kind": "road", "lon": 116.36, "lat": 39.76}],
  "edges": [{"a": "N0", "b": "N1", "dist_m": 82.4, "road": "创新道"}],
  "poi_access": {"B1": {"node": "P30", "road_node": "N12", "access_m": 18.3, "road": "忠诚道"}}
}
```
- `edges[].dist_m` 是**沿路网**的米数，直接做边权（`cost = dist_m / 1.3` 秒）。
- POI 到 POI 的路径：`P_id →(access)→ N →(路网)→ N →(access)→ P_id`。
- 想换算法：A* 用 `h = 直线距离/1.3`；多目标排序用带时间窗的 TSP（贪心 + 2-opt，或直接上 OR-Tools）。

## 七、局限与下一步

- 路网是从高德道路轴线概括的**主干路**，没有校内小径、楼梯、天桥、门禁；点位人工读点，需实地校正。
- 步行速度按 1.3 m/s 匀速；未考虑公安院校的集合、查铺、晚点名等硬时间点与限行。
- 平台目前是**单机版**（localStorage + JSON 导入导出），没有账号与云端同步。

## 八、日程规划引擎（v1，已可用）

平台右侧新增「今日计划」：选周几 + 周次 + 宿舍 → 「生成今日计划」，就把**课表 + 作息 + 队列 + 内务 + 个人习惯**排成一张时间轴，并在地图上画出当天动线的绿色虚线。

| 文件 | 作用 |
|---|---|
| `web/schedule_data.js` | 数据层：12 节次时间、铸剑楼 3-4 节推迟、全学期课表（含周次区间）、早集合/集合/吃饭/洗澡/熄灯、内务门禁、个人偏好 |
| `web/planner.js` | 引擎：锚点 + 全程填空隙；对「洗澡时段 × 午饭地点 × 晚饭前后」枚举打分（科研连续性 > 步行时间 > 就餐质量），课程迟到视为硬冲突重罚 |
| `web/app.js` | 面板渲染、新增事项对话框、本周对比、计划路径绘制 |

**规则怎么落进去的**

- 早集合按星期区分：周一/五跑操、周二/四队列操、周三内务操（06:25–06:35 起始）；7:40 宿舍楼下集合 → 队列行进至铸剑楼 → 各自去教室。
- 内务门禁：周中 08:00–15:30、18:20–20:30 不能回宿舍（盆必须留在宿舍）→ 洗澡只能安排在 15:30–18:20 或 20:30 之后；**周日必须在 15:00 大扫除前到宿舍**，引擎会自动把洗澡挪到上午。
- 午休时段宿舍是关的，所以「午休」排成就地（教室/餐厅）休息。
- 目标函数：最重「最长整块科研时间」（×2.2），其次总科研时长（×0.8），减去步行时间（×1.2）；课程迟到一次罚 400 分——所以引擎宁可少做科研，也不会让你旷课迟到。

**实测结果（第 7 周，宿舍按学生公寓7）**

| 天 | 科研总时长 | 最长整块 | 结论 |
|---|---|---|---|
| 周一 | 5 小时 44 分 | 3 小时 31 分 | 上午没课，是最肥的整块 |
| 周四 | 53 分钟 | 53 分钟 | 五节课 + 晚课，几乎榨不出整块 |
| 周日 | 10 小时 31 分 | 4 小时 28 分 | 但 15:00 前必须洗完澡 |
