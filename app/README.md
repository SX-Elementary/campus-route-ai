# 个人科研工作生活平台

本地运行的个人任务与科研节奏管理工具。数据仅保存在浏览器 `localStorage`，可用左侧「导出备份」保存成本地 JSON 文件。

## 运行

在本目录执行：

```powershell
python -m http.server 4180
```

然后打开 <http://127.0.0.1:4180>。

## 当前功能

- Inbox/本周计划/进行中/待验证/待汇报/已完成看板；
- 上午、中午、下午、晚上四时段任务视图；
- 本地任务保存；
- 周报草稿复制；
- 项目、学习、运动任务分类；
- 点击任意任务卡片（今日专注、工作流看板、项目看板、本周归档）即可回到任务界面重新编辑，保存后更新原任务；
- 项目看板：展开任务后按颜色区分已完成 / 待完成，按钮只显示未完成的任务数；
- 项目看板：把任务卡片拖到其他项目上即可更改任务所属项目（跨流线时同时切换流线，可撤销）；
- 项目看板：拖动项目卡片调整顺序，或用上下箭头。
